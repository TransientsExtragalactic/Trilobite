compute_accretion_luminosity(time: Any, interpolator=None, **interp_kwargs) → Quantity[source]#

Compute the accretion luminosity as a function of time.

This is the rate at which gravitational energy is released as mass spirals in from the outer disk to the inner truncation radius:

\[L_{\rm acc}(t) = \frac{G\,M_{\rm BH}\,\dot{M}(t)}{2\,R_{\rm in}}\]

\(\dot{M}\) is interpolated from the result at time and \(R_{\rm in}\) is read from the stored runtime parameters [1].

Note

\(L_{\rm acc}\) represents the total power released by viscous dissipation. In radiatively efficient models (no advection) essentially all of this power escapes as radiation, so \(L_{\rm acc} \approx L_{\rm rad}\). In advection-dominated models (e.g. AdvectiveDisk) a fraction of the dissipated energy is advected inward rather than radiated, giving \(L_{\rm rad} < L_{\rm acc}\). Use compute_radiative_luminosity() to obtain the Stefan-Boltzmann luminosity directly from \(T_{\rm eff}\).

Parameters:

  • time (float or Quantity) – Time at which to evaluate the luminosity. Scalar or array.

  • interpolator (callable, optional) – Pre-built spline for the "mdot" field. Built on-the-fly if None. When provided, **interp_kwargs are ignored.

  • **interp_kwargs – Passed to get_field_interpolator() when building the spline on-the-fly. Use ext=0 to extrapolate beyond the simulation time range instead of raising ValueError (the default).

Returns:

Accretion luminosity in erg s⁻¹, same shape as time.

Return type:

~astropy.units.Quantity

Raises:

ValueError – If time is outside the simulation range and ext=2 (default).

See also

compute_radiative_luminosity

Stefan-Boltzmann luminosity from \(T_{\rm eff}\) — the power actually radiated from the disk surface.

Examples

L_acc = result.compute_accretion_luminosity(
    1e8 * u.s
)
print(L_acc.to(u.Lsun))

# Allow extrapolation beyond the simulation time range
L_acc = result.compute_accretion_luminosity(
    1e10 * u.s, ext=0
)

compute_radiative_luminosity(time: Any, T_interpolator=None, R_interpolator=None, **interp_kwargs) → Quantity[source]#

Compute the Stefan-Boltzmann bolometric luminosity at time.

Treats the disk as an annular blackbody of uniform effective temperature \(T_{\rm eff}\) radiating from both faces:

\[L_{\rm rad}(t) = 2\pi\,\sigma_{\rm SB}\,T_{\rm eff}^4(t)\, \bigl(R_D^2(t) - R_{\rm in}^2\bigr)\]

Because the one-zone model sets \(T_{\rm eff}\) by the local energy balance, \(L_{\rm rad}\) equals the power that actually escapes the disk surface as thermal radiation. In advection-dominated models this is less than compute_accretion_luminosity().

Parameters:

  • time (float or Quantity) – Time at which to evaluate the luminosity. Scalar or array.

  • T_interpolator (callable, optional) – Pre-built spline for the "T_eff" field. Built on-the-fly if None. When provided, **interp_kwargs are ignored for this field.

  • R_interpolator (callable, optional) – Pre-built spline for the "R_D" field. Built on-the-fly if None. When provided, **interp_kwargs are ignored for this field.

  • **interp_kwargs – Passed to get_field_interpolator() for any field whose interpolator is built on-the-fly. Use ext=0 to extrapolate beyond the simulation time range instead of raising ValueError (the default).

Returns:

Radiative luminosity in erg s⁻¹, same shape as time.

Return type:

~astropy.units.Quantity

Raises:

ValueError – If time is outside the simulation range and ext=2 (default).

See also

compute_accretion_luminosity

Gravitational power released — differs from this quantity when advective cooling is significant.

compute_spectral_luminosity

Monochromatic version; integrates to \(L_{\rm rad}\).

Examples

L_rad = result.compute_radiative_luminosity(
    1e8 * u.s
)
print(L_rad.to(u.Lsun))

# compare to accretion luminosity (equal for non-advective models)
L_acc = result.compute_accretion_luminosity(
    1e8 * u.s
)
print(L_rad / L_acc)  # < 1 for AdvectiveDisk
compute_spectral_luminosity(nu: Any, time: Any, T_interpolator=None, R_interpolator=None, **interp_kwargs) → Quantity[source]#

Compute the blackbody spectral luminosity of the disk at time.

Treats the disk as a single-temperature Lambertian emitter at \(T_{\rm eff}(t)\) and evaluates the Planck function over both faces:

\[L_\nu(t) = 2\pi^2\,B_\nu\!\bigl(T_{\rm eff}(t)\bigr)\, \bigl(R_D^2(t) - R_{\rm in}^2\bigr)\]

Integrating over all frequencies recovers compute_radiative_luminosity().

See also

compute_sed() provides a more accurate multi-colour SED using the full SS73 radial temperature profile.

Parameters:

  • nu (float or array-like or ~astropy.units.Quantity) – Frequency or frequency array [Hz].

get_field_interpolator(field_name: str, **kwargs)[source]#

Return a cubic spline interpolator for a result field as a function of time.

Builds an InterpolatedUnivariateSpline (default k=3, ext=2) on the stored time grid. The returned callable accepts time in seconds and returns raw float values (units must be looked up separately from RESULT_FIELDS or the known built-in fields).

By default the interpolator raises ValueError if evaluated outside the simulation time range (ext=2). Pass ext=0 to extrapolate, ext=1 to return zero, or ext=3 to clamp to the boundary value.

Parameters:

  • field_name (str) – Name of a field in data ("t", "M_D", "J_D", or any RESULT_FIELDS key).

  • **kwargs – Forwarded to InterpolatedUnivariateSpline (e.g. k=1 for linear interpolation, ext=0 to allow extrapolation beyond the simulation time range).

Returns:

Callable f(t_s) -> float where t_s is time in seconds.

Return type:

~scipy.interpolate.InterpolatedUnivariateSpline

Raises:

KeyError – If field_name is not present in data.

Examples

)

interpolate_field(field_name: str, t_new: Any, interpolator=None, **kwargs) → Quantity | ndarray[source]#

Evaluate a result field at arbitrary time(s) via spline interpolation.

By default a ValueError is raised when t_new falls outside the simulation time range. Pass ext=0 to extrapolate, ext=1 to return zero, or ext=3 to clamp to the boundary value instead. These are forwarded to get_field_interpolator() only when no pre-built interpolator is supplied; if a pre-built interpolator is provided, **kwargs are ignored and the interpolator’s own ext setting applies.

Parameters:

  • field_name (str) – Name of a field in data.

  • t_new (float or Quantity or array-like) – Time(s) at which to evaluate the field. Quantities are converted to seconds automatically.

  • interpolator (callable, optional) – A pre-built spline from get_field_interpolator(). If None, one is built on-the-fly.

  • **kwargs – Forwarded to get_field_interpolator() when interpolator is None (e.g. ext=0 to allow extrapolation, k=1 for linear interpolation).

Returns:

Interpolated value(s) with units attached when the field declares them in RESULT_FIELDS.

Return type:

~astropy.units.Quantity or numpy.ndarray

Raises:

ValueError – If t_new is outside the simulation time range and ext=2 (the default).

to_hdf5(filename: str | Path, overwrite: bool = False) → None[source]#

Write the result to an HDF5 file.

The model specification is serialised as a JSON string stored in an HDF5 attribute, so the model can be reconstructed automatically by from_hdf5() without any user-supplied configuration.

File layout:

result.h5
├── [attr] format      : "OneZoneAccretionResult"
├── [attr] version     : str  (trilobite package version)
├── [attr] model_spec  : JSON str  ← model.to_spec_dict()
├── [attr] run_params  : JSON str  ← processed float dict
├── [attr] success     : bool
├── [attr] message     : str
├── result_array : float64, shape (n_result_fields, N)  [linear CGS]
└── extra_fields/  : group; present only if add_field() was called
    └── <name>     : float64, shape (N,)  [attr: units="..."]
Parameters:

  • filename (str or Path) – Output path for the HDF5 file. The parent directory must already exist.

  • overwrite (bool, optional) – If False (the default) and the file already exists, raise FileExistsError without modifying the file. Set to True to silently replace an existing file.

Raises:

FileExistsError – If filename already exists and overwrite=False.

Examples

result.to_hdf5("disk_run.h5")

# Overwrite a previous run:
result.to_hdf5("disk_run.h5", overwrite=True)

See also

from_hdf5

Class method to load a result from a file written by this method.
