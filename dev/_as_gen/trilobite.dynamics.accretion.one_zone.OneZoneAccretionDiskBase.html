OneZoneAccretionDiskBase#

class trilobite.dynamics.accretion.one_zone.OneZoneAccretionDiskBase(**context_parameters)[source]#

Bases: ABC

Abstract base class for one-zone accretion disk models.

A one-zone disk model collapses the two-dimensional disk structure into two global, time-evolving variables: disk mass \(M_D\) and angular momentum \(J_D\). All other physical quantities are recovered at each timestep via a declarative closure pipeline whose steps are defined by subclass implementations.

Notes

The ODE system

The model evolves disk mass \(M_D\) and angular momentum \(J_D\) via a compiled Cython explicit-Euler integrator. All structural, thermodynamic, and viscous quantities are computed inside the Cython hot loop at every timestep.

Declarative parameter system

Subclasses declare their parameters through four class-level dictionaries:

  • CONTEXT_PARAMETERS — constructor arguments (e.g. equation of state parameters, one-zone correction factors).

  • RUNTIME_PARAMETERS — per-solve physics inputs (e.g. black hole mass, inner truncation radius, \(\alpha\)).

  • INITIAL_CONDITIONS — ODE initial state (\(M_{D,0}\), \(J_{D,0}\)).

  • RESULT_FIELDS — derived quantities exposed via the result.

Each entry specifies the expected units, whether the value is log- transformed before storage, and an optional default.

Implementing a new model

Subclass OneZoneAccretionDiskBase, then:

  1. Populate the four declaration dicts and CYTHON_FIELD_MAP.

  2. Implement _build_cython_closure() to return the compiled closure.

  3. Implement to_spec_dict() and from_spec_dict() for HDF5.

from astropy import constants as const
from astropy import units as u
from trilobite.dynamics.accretion.one_zone import (
    gP_esDisk,
)

disk = gP_esDisk(mu=0.62)

result = disk.solve(
    initial_conditions={
        "M_D_0": 0.1 * const.M_sun,
        "J_D_0": 1.5e49 * u.g * u.cm**2 / u.s,
    },
    runtime_parameters={
        "M_BH": 3.0 * const.M_sun,
        "R_in": 3.0e6 * u.cm,
        "alpha": 0.1,
    },
    t_span=(1.0e6 * u.s, 5.0e9 * u.s),
    max_steps=50_000,
)

print(result.success, result.n_steps)
data = result.data
result.to_hdf5("disk_run.h5", overwrite=True)

CONTEXT_PARAMETERS: dict[str, dict] = {}#

Constructor (context) parameters.

Each entry maps a parameter name to a schema dict:

{
    "description": str,      # human-readable label
    "base_units":  str|None, # astropy unit string; None = dimensionless
    "default":     value,    # None means required
}

Values are stored verbatim in _context_parameters and are available for the lifetime of the model instance.

Notes

For developers, the context parameters should be used for hyperparameters which are not relevant in inference implementations. Thus, we should not place parameters in the context parameters if they would require re-instantiation of the disk engine everytime they are changed.

Type:

dict

CYTHON_FIELD_MAP: dict = {}#

Mapping from RESULT_FIELDS keys to Cython result row indices.

Each entry maps a field name to either an int row index in the Cython result array (result_array[idx, :]), or None if the field is computed as a derived quantity in Python inside OneZoneAccretionResult.data.

Every key in RESULT_FIELDS must appear here; missing keys are rejected by _OneZoneMeta at class-definition time.

dict

INITIAL_CONDITIONS: dict[str, dict] = {}#

ODE initial-condition declarations.

Same schema as RUNTIME_PARAMETERS. process_initial_conditions() iterates this dict in declaration order and packs values into the state vector y0 passed to the ODE solver.

The initial conditions may ONLY include the ODE state variables (e.g. \(M_{D,0}\), \(J_{D,0}\)) and not any auxiliary parameters (e.g. \(R_{D,0}\), \(t_{\rm visc,0}\)) which are computed self-consistently from the state variables and context parameters.

dict

{

    "units":       str|None,  # astropy unit string; None = dimensionless
}

Fields are read from the Cython result array by row index (see CYTHON_FIELD_MAP), or computed as derived quantities in Python.

dict

RUNTIME_PARAMETERS: dict[str, dict] = {}#

Per-solve runtime parameters.

Each entry maps a parameter name to a schema dict:

{
    "description":   str,
    "base_units":    str|None,
    "default":       value,    # None means required
    "log_transform": bool,     # True → stored as log(CGS value)
}

generate_initial_conditions(M_BH: Any, M_D_0: Any | None = None, J_D_0: Any | None = None, R_D_0: Any | None = None) → dict[source]#

Compute a complete set of initial conditions from any two of the three disk state variables.

Uses the Metzger+08 kinematic constraint

\[J_D = \xi\, M_D \sqrt{G M_{\rm BH} R_D}, \qquad \xi \equiv B / A,\]

to infer the missing variable. Exactly two of M_D_0, J_D_0, R_D_0 must be supplied; the third is computed and included in the returned dict.

Parameters:

  • M_BH (float or Quantity) – Black hole mass. Converted to grams if a Quantity is supplied.

  • M_D_0 (float or Quantity, optional) – Initial disk mass. Converted to grams if a Quantity is supplied.

  • J_D_0 (float or Quantity, optional) – Initial disk angular momentum. Converted to g cm² s⁻¹ if a Quantity is supplied.

  • R_D_0 (float or Quantity, optional) – Initial disk outer radius. Converted to cm if a Quantity is supplied.

Returns:

{"M_D_0": Quantity [g], "J_D_0": Quantity [g cm² s⁻¹]} — the two keys consumed by solve().

Return type:

dict

Raises:

  • AttributeError – If the subclass does not define _A and _B (the Metzger+08 geometry constants).

  • ValueError – If the number of supplied variables is not exactly two.

Examples

ic = disk.generate_initial_conditions(
    M_BH=3.0 * const.M_sun,
    M_D_0=0.1 * const.M_sun,
    R_D_0=3.0e13 * u.cm,
)
result = disk.solve(
    initial_conditions=ic,
    runtime_parameters={
        "M_BH": 3.0 * const.M_sun,
        "R_in": 3.0e6 * u.cm,
        "alpha": 0.1,
    },
    t_span=(1.0e6 * u.s, 5.0e9 * u.s),
)
process_initial_conditions(initial_conditions: dict[str, Any]) → ndarray[source]#

Validate and pack initial conditions into a CGS state vector.

Iterates over INITIAL_CONDITIONS in declaration order, applying the same validation and unit-conversion logic as process_runtime_parameters(). The resulting values are assembled into a 1-D NumPy array in the order the keys appear in INITIAL_CONDITIONS.

This converts the dictionary of initial conditions into the form expected by the Cython-level ODE solver.

Parameters:

initial_conditions (dict) – User-supplied initial conditions. Values may be plain floats or Quantity objects.

Returns:

State vector y0 of shape (n_ic,), where n_ic = len(INITIAL_CONDITIONS). Each element is the log-CGS or plain-CGS representation of the corresponding initial condition, ready for the Cython integrator (run_one_zone_model()).

Return type:

np.ndarray

Raises:

ValueError – If a required initial condition is absent from initial_conditions.

Examples

from astropy import constants as const
from astropy import units as u

y0 = disk.process_initial_conditions(
    {
        "M_D_0": 0.1 * const.M_sun,
        "J_D_0": 1.5e49 * u.g * u.cm**2 / u.s,
    }
)
# y0[0] = log(M_D_0 in g),  y0[1] = log(J_D_0 in g cm^2 / s)
process_runtime_parameters(runtime_parameters: dict[str, Any]) → dict[str, float][source]#

Validate and convert runtime parameters to a log-CGS float dict.

Iterates over RUNTIME_PARAMETERS in declaration order. For each parameter:

  • The value is taken from runtime_parameters if present, or the declared "default" is used if not None.

  • Missing required parameters ("default": None) raise ValueError with the parameter name in the message.

  • Unit-bearing values are converted to "base_units" via ensure_in_units().

  • If "log_transform": True, the result is stored as "log_{key}": np.log(cgs_value); otherwise as "{key}": float(cgs_value).

Parameters:

runtime_parameters (dict) – User-supplied runtime parameters. Values may be plain floats or Quantity objects; unit conversion is applied automatically.

Returns:

Flat dict of plain floats (or log-floats) ready for use in the closure pipeline. No unit objects are present in the returned dict.

Return type:

dict

Raises:

ValueError – If a required parameter (one with "default": None) is absent from runtime_parameters.

Examples

from astropy import constants as const
from astropy import units as u

run_params = disk.process_runtime_parameters(
    {
        "M_BH": 3.0 * const.M_sun,
        "R_in": 3.0e6 * u.cm,
        "alpha": 0.1,
    }
)
# M_BH is log-transformed:
print(
    run_params["log_M_BH"]

# alpha is not log-transformed:

solve(initial_conditions: dict, runtime_parameters: dict, t_span: tuple[Any, Any], max_steps: int = 100000, epsilon: float = 1e-06, fail_fast: bool = True) → OneZoneAccretionResult[source]#

Solve the one-zone disk evolution equations via the Cython integrator.

Processes the user-supplied parameters and initial conditions into linear CGS, passes them to the compiled Cython integrator, and returns the solution as a OneZoneAccretionResult.

Parameters:

  • initial_conditions (dict) – Initial state of the disk. Keys must match those declared in INITIAL_CONDITIONS (e.g. "M_D_0", "J_D_0"). Values may be plain floats or Quantity objects; unit conversion is applied automatically.

  • runtime_parameters (dict) – Per-solve physics parameters. Keys must match those declared in RUNTIME_PARAMETERS (e.g. "M_BH", "R_in", "alpha").

  • t_span (tuple) – Integration interval (t_start, t_end); values may be plain floats (seconds) or Quantity objects.

  • max_steps (int, optional) – Maximum number of integration steps. Default is 100 000.

  • epsilon (float, optional) – Adaptive time-step fraction passed to the Cython integrator. The step size is \(\Delta t = \epsilon\,\min(t_{\rm visc}, |M/\dot{M}|, |J/\dot{J}|)\). Must be in (0, 1). Default is 1e-6.

  • fail_fast (bool, optional) – If True (default), raise RuntimeError when the integrator signals failure. If False, issue a warning and return the (possibly incomplete) result.

Returns:

Result containing the raw Cython result array, the processed runtime parameters, and solver metadata.

Return type:

OneZoneAccretionResult

Examples

from astropy import constants as const
from astropy import units as u

    gP_esDisk,
)

    initial_conditions={
        "M_D_0": 0.1 * const.M_sun,

    runtime_parameters={
        "M_BH": 3.0 * const.M_sun,
        "R_in": 3.0e6 * u.cm,
        "alpha": 0.1,

    t_span=(1.0e6 * u.s, 5.0e9 * u.s),

solve_initial_state(initial_conditions: dict, runtime_parameters: dict, t_span: tuple[Any, Any], fail_fast: bool = True) → OneZoneAccretionResult[source]#

Evaluate the closure at the initial state without integrating forward.

Runs the Cython integrator for exactly one step, so the returned result contains a single column (column 0) that holds the initial conditions with their full thermodynamic closure computed. The state is not evolved; this call is therefore much cheaper than a full solve() and is useful for:

  • Checking that initial conditions produce physically reasonable derived quantities before committing to a long run.

  • Inference pipelines that need to evaluate the disk state at a single point in time without stepping forward.

Parameters:

  • initial_conditions (dict) – Initial state of the disk (same keys as solve()).

  • runtime_parameters (dict) – Per-solve physics parameters (same keys as solve()).

  • t_span (tuple) – Integration interval (t_start, t_end); only t_start is used (t_end must be strictly greater, but the integrator will write column 0 and return after one step regardless).

  • fail_fast (bool, optional) – Forwarded to solve().

Returns:

Result with n_steps == 1; result_array has shape (n_result_fields, 1).

Return type:

OneZoneAccretionResult

Examples

result = disk.solve_initial_state(
    initial_conditions={
        "M_D_0": 0.1 * const.M_sun,
        "J_D_0": 1.5e49 * u.g * u.cm**2 / u.s,
    },
    runtime_parameters={
        "M_BH": 3.0 * const.M_sun,
        "R_in": 3.0e6 * u.cm,
        "alpha": 0.1,
    },
    t_span=(1.0e6 * u.s, 5.0e9 * u.s),
)
print(
    result.data["T_c"]
)  # midplane temperature at t_start
solve_parameter_grid(initial_conditions_grid: dict[str, list], runtime_parameters_grid: dict[str, list], t_span: tuple[Any, Any], max_steps: int = 100000, fail_fast: bool = False) → dict[tuple, OneZoneAccretionResult][source]#

Solve the disk ODE for every combination of grid parameter values.

Takes a grid of possible values for each initial condition and runtime parameter, constructs all combinations with itertools.product(), and calls solve() for each. Progress is tracked with a tqdm progress bar that respects the project configuration.

Parameters:

  • initial_conditions_grid (dict[str, list]) – Maps each initial-condition key to the list of values to sweep. Keys must match INITIAL_CONDITIONS. Parameters not listed here take their declared default (or must be present in every initial_conditions call — i.e. they must have a default).

  • runtime_parameters_grid (dict[str, list]) – Maps each runtime-parameter key to the list of values to sweep. Keys must match RUNTIME_PARAMETERS.

  • t_span (tuple) – Integration interval (t_start, t_end) forwarded to every solve() call.

  • max_steps (int, optional) – Maximum integration steps per solve. Default 100 000.

  • fail_fast (bool, optional) – If True, re-raise the first integration error and abort the sweep. If False (default for grid runs), store the failed result and continue.

Returns:

Maps each parameter combination, encoded as a tuple of (key, value) pairs sorted alphabetically by key, to the corresponding OneZoneAccretionResult.

Return type:

dict[tuple, OneZoneAccretionResult]

Examples

from astropy import constants as const
from astropy import units as u

results = disk.solve_parameter_grid(
    initial_conditions_grid={
        "M_D_0": [
            0.05 * const.M_sun,
            0.1 * const.M_sun,
        ]
    },
    runtime_parameters_grid={
        "alpha": [0.05, 0.1],
        "M_BH": [3.0 * const.M_sun],
    },
    t_span=(1e6 * u.s, 5e9 * u.s),
)
for combo, result in results.items():
    print(
        dict(combo),
        result.success,
        result.n_steps,
    )
test_initial_state(initial_conditions: dict, runtime_parameters: dict, t_span: tuple[Any, Any]) → dict[source]#

Return a diagnostic report for the closure at the initial state.

Calls solve_initial_state() and inspects the resulting derived quantities for physical consistency. No exceptions are raised; each check is reported as a (passed, value, note) tuple so the caller can decide how to react.

Checks performed#

  • finite — every result field is finite and non-NaN.

  • T_c_positive — midplane temperature is positive.

  • tau_thick — optical depth \(\tau \geq 1\) (thick-disk assumption valid).

  • H_over_R — \(H/R < 1\) (geometrically thin-disk assumption valid).

  • R_D_gt_R_in — disk outer radius exceeds the inner truncation radius (disk not fully drained).

param initial_conditions:

Forwarded to solve_initial_state().

type initial_conditions:

dict

param runtime_parameters:

Forwarded to solve_initial_state().

type runtime_parameters:

dict

param t_span:

Forwarded to solve_initial_state().

type t_span:

tuple

returns:

Keyed by check name. Each value is a dict:

{
    "passed": bool,
    "value":  the computed quantity (Quantity or float),
    "note":   str description,
}

An additional "result" key holds the raw OneZoneAccretionResult.

rtype:

dict

Examples

report = disk.test_initial_state(
    initial_conditions={
        "M_D_0": 0.1 * const.M_sun,
        "J_D_0": 1.5e49 * u.g * u.cm**2 / u.s,
    },
    runtime_parameters={
        "M_BH": 3.0 * const.M_sun,
        "R_in": 3.0e6 * u.cm,
        "alpha": 0.1,
    },
    t_span=(1.0e6 * u.s, 5.0e9 * u.s),
)
for name, chk in report.items():
    if name == "result":
        continue
    status = "OK" if chk["passed"] else "FAIL"
    print(
        f"  [{status}] {name}: {chk['value']}  — {chk['note']}"
    )
