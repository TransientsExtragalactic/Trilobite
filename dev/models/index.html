Models#

A searchable catalog of every forward model in Trilobite.

Browse GRB, supernova, TDE and LFBOT models, each labeled with its development status.

Trilobite provides an ever-expanding collection of forward models for astrophysical inference, phenomenological curve fitting, and physically motivated transient modeling. Models range from lightweight mathematical forms to physically grounded shock and emission models, and all share the unified Model interface: consistent parameter handling, unit support, and compatibility with likelihood and inference tools.

New to the framework?

Start with the Trilobite Models: design philosophy, ModelParameter and ModelVariable, unit handling, inference integration, and how to write your own model.

Can’t find your model?

Most models are designed to be subclassed. Phenomenological models adapt with minimal effort, and physical models expose their core components so assumptions can be modified cleanly.

Development status#

Every model carries a development stage, shown as a badge in the tables below and at the top of its API page. The stage is declared on the model class with the STATUS attribute (see ModelStatus), so it can never drift from the code. Instantiating an experimental or deprecated model emits a warning.

Verified

Backed by a verification test against published results or an independent reference.

Novel

New physics with no published counterpart to verify against.

Unverified

Implemented and tested, but not yet verified.

Experimental

Under active development; physics, parameters or API may change without notice.

Deprecated

Scheduled for removal; prefer the suggested replacement.

LFBOT Models#

Circumstellar interaction of luminous fast blue optical transients (LFBOTs). The two-component model follows an equatorial and a polar sightline through an axisymmetric CSM, each with its own thin-shell shock, synchrotron emission and free-free attenuation. It provides both a paired (time, frequency) path for inference and a tabulate path for analysis and plotting.

Optical Models#

Filter-convolved flux densities for multi-band photometric observations. Optical models are built on the OpticalModel and OpticalEpochModel abstract base classes, which handle FilterBundle convolution, time deduplication, and band-index resolution automatically. See the optical model pattern for a guide to implementing custom optical models.

Extending the Model Library#

Every model subclasses Model, declaring its PARAMETERS and VARIABLES and implementing the forward model. The Trilobite Models walks through a complete worked example (The Forward Modelling Directive, Model Parameters and Variables) and covers specialized patterns such as the optical model pattern.
